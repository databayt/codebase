## Usage

```tsx
import {
  NativeSelect,
  NativeSelectOption,
} from "@/components/ui/native-select"
```

```tsx
<NativeSelect>
  <NativeSelectOption value="">Select status</NativeSelectOption>
  <NativeSelectOption value="todo">Todo</NativeSelectOption>
  <NativeSelectOption value="done">Done</NativeSelectOption>
</NativeSelect>
```

Use the native select when a plain platform control is enough — it needs no
JavaScript, works inside forms out of the box, and inherits RTL behavior from
the browser. Reach for the composed `Select` when you need custom item
rendering or grouped commands.
