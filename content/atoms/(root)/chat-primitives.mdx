## Usage

```tsx
import { Message, MessageAvatar, MessageContent, MessageGroup } from "@/components/ui/message"
import { Bubble, BubbleContent, BubbleGroup } from "@/components/ui/bubble"
import { Attachment, AttachmentContent, AttachmentMedia, AttachmentTitle } from "@/components/ui/attachment"
import { Marker, MarkerContent } from "@/components/ui/marker"
```

```tsx
<MessageGroup>
  <Message>
    <MessageAvatar>AI</MessageAvatar>
    <MessageContent>Hello!</MessageContent>
  </Message>
  <Message align="end">
    <MessageContent>Hi there.</MessageContent>
  </Message>
</MessageGroup>
```

Five primitives compose the chat surface: `Message` rows with avatars and
footers, `Bubble` for short grouped exchanges, `Attachment` for files and
media, `Marker` for date separators and annotations, and `MessageScroller`
for an auto-following viewport during streaming. All of them align with
logical properties, so `align="end"` lands on the correct side in Arabic.
